# Stargazer

A one-object web museum for the Cleveland Museum of Art’s marble *Stargazer* (1993.165).

The app uses public data: Cleveland’s Open Access photogrammetry mesh and photographs (CC0), plus published excavation accounts of the Kulaksızlar workshop in western Anatolia.

Turn the mesh in the vitrine, download the object file, and read the workshop essay — site, making, type, proportion, meaning, and find spots.

## The object

- Accession 1993.165, marble, 17.2 × 6.5 × 6.3 cm
- Western Anatolia, Kilia type
- Official CMA Open Access photogrammetry mesh (CC0)
- Production context: Kulaksızlar, near Akhisar, Manisa

[Cleveland object page](https://www.clevelandart.org/art/1993.165)

## In the app

- 3D vitrine (surface, form, mesh, x-ray)
- Downloadable GLB (`stargazer-1993.165.glb`)
- Workshop essay: site, making, type, proportion, meaning, finds
- Account / login

## Run locally

```bash
npm install
npm run dev
```

Vite serves the app at [http://localhost:8080](http://localhost:8080).
